# Build in Public — CareScribe

This repository documents the ongoing development of CareScribe — a documentation review system designed to support care professionals in identifying gaps, inconsistencies, and missing context in records before review.

---

## Why Build in Public?

Care documentation is a high-responsibility environment.

Decisions around how records are written, reviewed, and interpreted have real-world implications — for care quality, accountability, and inspection outcomes.

This project is being developed openly to:

- Make assumptions visible  
- Document reasoning behind product decisions  
- Invite feedback from care professionals  
- Ensure the system reflects real-world workflows  

---

## What is CareScribe?

CareScribe is being developed as a **documentation review layer**.

It focuses on supporting:

- Identification of narrative gaps  
- Highlighting incomplete or unclear entries  
- Surfacing potential inconsistencies  
- Improving clarity and structure in records  

It does **not** replace professional judgment or compliance processes.

---

## Current Focus Areas

- Narrative gap identification  
- Documentation consistency signals

## How This Repository is Structured

### `/simulations/`

---

### `/insights/`
Observed patterns and recurring issues in care documentation  
→ Based on research, outreach, and feedback  

---

### `/logic/`
Rule-based reasoning that powers documentation review  
→ Transparent, explainable logic (no black-box assumptions)  

---

### `/validation/`
Feedback and usability insights from care professionals  
→ What works, what doesn’t, what needs refinement
